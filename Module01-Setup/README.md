## 📖 Overview

Module 1 focuses on preparing the development environment and establishing the GitHub workflow that will be used throughout the course.

The goal of this module is to create a reliable workspace for developing, testing, organizing, and maintaining C++ projects while becoming familiar with version control and repository organization.

This repository will continue to grow as new concepts are introduced throughout the course.

## 💻 Development Workflow

Throughout this course, I will follow the general development process:

```text
Plan
  ↓
Write Code
  ↓
Compile
  ↓
Test
  ↓
Improve
  ↓
Commit
  ↓
Push to GitHub
  ↓
Verify
```

This allows each version of the application to be documented as it develops.

---

## 🔄 GitHub Workflow

The basic Git workflow introduced in this module is:

```bash
git add .
git commit -m "Add Module 1 assignment"
git push
```

### What These Commands Do

| Command | Purpose |
|---|---|
| `git add .` | Stages project changes for the next commit |
| `git commit` | Creates a recorded checkpoint of the project |
| `git push` | Uploads local commits to the GitHub repository |
