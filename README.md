## ▶️ Building & Running

Compilation instructions will be expanded as the application develops.

A basic C++ source file can be compiled using a compatible C++ compiler.

Example with `g++`:

```bash
g++ program.cpp -o program
```

Run on Windows:

```bash
program.exe
```

Or on Linux/macOS:

```bash
./program
```

Module-specific instructions can be found inside the README for each module.
